How to execute/run the system in the Linux terminal:
1. RUN make or make all to build the system, compile everything together
2. RUN:
	a) make run1 for FCFS simulation output
	b) make run2 for Round Robin simulation output
	c) make run3 for Priority scheduling simulation output
	d) make run4 for Shortest Job First simulation output
	e) make runall for simulation output of all algorithms, starting from a) above to d), that is, from FCFS to SJF.
3. RUN make clean to delete all object files.
